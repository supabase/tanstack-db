# @supabase/tanstack-db

[Supabase](https://supabase.com) collection adapter for [TanStack DB](https://tanstack.com/db). Use TanStack DB with your Supabase Postgres tables for typed collections, supporting all CRUD operations with optional realtime.

## Installation

```bash
pnpm add @supabase/tanstack-db @tanstack/react-db @tanstack/query-db-collection @supabase/supabase-js
```
